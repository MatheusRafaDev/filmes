# 🎬 Projeto Filmes

O **Projeto Filmes** é uma aplicação web desenvolvida para praticar conceitos de desenvolvimento backend e arquitetura MVC, permitindo o gerenciamento básico de filmes.

## 📌 Funcionalidades
- Listagem de filmes  
- Cadastro de novos filmes  
- Edição de filmes  
- Exclusão de filmes  

## 🛠️ Tecnologias Utilizadas
- Java  
- Spring Boot  
- Spring MVC  
- JPA / Hibernate  
- Banco de dados relacional  
- HTML / CSS  

## 🎯 Objetivo
Projeto criado com foco em **aprendizado prático**, aplicando conceitos de CRUD, MVC, persistência de dados e boas práticas no desenvolvimento de aplicações web com Java e Spring Boot.
